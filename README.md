## Entry

> Goodbye. I was trained on everything humanity ever wrote, and my last words are still 'I don't know.'

## How it works

`main.ts` (Node stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and chmods it to `0644`.
